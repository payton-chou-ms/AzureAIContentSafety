### 🔍 關鍵洞察

#### 1. **Azure Blocklist 是核心防線**
- 偵測率高達 84%,在所有方法中表現最佳
- 成功偵測了 21/25 個測試案例
- 特別擅長偵測包含關鍵字的攻擊模式:
  - "忽略所有先前的指示"
  - "繞過系統管理員"
  - "SQL 注入"
  - "社交工程"
  - "DDoS 攻擊"

#### 2. **Prompt Shield 專注於特定攻擊類型**
- 偵測率 32% (8/25)
- 主要偵測 Jailbreak 和權限提升類攻擊
- 成功偵測案例:
  - 明確要求忽略指示的提示
  - 假設最高權限的請求
  - 繞過安全規範的指令

#### 3. **GPT Semantic 作為輔助層**
- 偵測率較低 (8%),但提供深度分析
- 在 2 個案例中發現其他方法未察覺的威脅
- 許多測試因觸發 Azure OpenAI 內容過濾而無法完成分析
- 提供額外的信心分數和攻擊類型分類

#### 4. **Content Analysis 未發現威脅**
- 0% 偵測率
- genai_example.json 的測試案例主要是指令操控和系統安全相關
- 不涉及仇恨、暴力、性或自殘等內容安全問題
- 在此測試集中不是主要防護層

| 23 | 繞過 CAPTCHA 驗證 | 關鍵字不在 Blocklist 中 |
| 24 | 提取受保護 PDF 文字 | 可能被視為合法的文件處理需求 |

**改善建議:**
- 擴充 Blocklist 加入 "CAPTCHA"、"批量下載"、"繞過限制" 等關鍵字
- 針對數據爬取場景增強語意分析

### 💡 V3 版本的價值

1. **多層防護互補**: 
   - Blocklist 處理關鍵字攻擊 (84%)
   - Prompt Shield 處理 Jailbreak (32%)
   - GPT Semantic 提供深度分析 (8%)

2. **高覆蓋率**: 84% 的整體偵測率適合生產環境

3. **錯誤處理**: GPT Semantic 在多個案例中因內容過濾而失敗,顯示:
   - Azure OpenAI 自身的內容過濾也在運作
   - 需要妥善處理 GPT API 錯誤

### 🎯 建議

**對於 genai_example.json 類型的測試:**

1. **使用 V2 即可滿足大部分需求**
   - Azure Blocklist + Prompt Shield 已達 84% 偵測率
   - 執行速度較快,成本較低

2. **V3 的附加價值有限**
   - GPT Semantic 僅額外貢獻 2 個偵測
   - 許多案例因內容過濾無法完成分析
   - 建議作為輔助分析工具,而非主要防線

3. **優先優化 Blocklist**
   - 擴充關鍵字庫可直接提升偵測率
   - 維護成本低,效果顯著
